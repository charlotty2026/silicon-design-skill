# 示例文章：AI 总自作主张？给它画三条红线

> 栏目：专项攻略
> 作者：佛跳墙
> 日期：2026-07-24

## 一、红线一：不碰报价

AI 在报价区绝对不能动手。报价数字是客户的底线，改一个数字可能丢一个单子。

### （一）具体怎么做

在系统提示词里写死：**报价区域的内容只字不改**。

```
你是排版助手。
报价区域的内容只字不改。
如果不确定，问人，别自己编。
```

### （二）为什么

AI 不懂商业逻辑。它觉得"800元"和"8000元"都是数字，改了也没关系。但对你来说，这可能是能不能中标的事。

## 二、红线二：不编资质

标书里写"我们有ISO9001认证"，AI 可能会"帮"你补充更多资质。这些补充的内容，你没有证书，就是造假。

### （一）正确做法

**给AI一份资质清单，让它只参考清单，不自己加。**

```
可用资质清单：
- ISO9001 质量管理体系认证
- ISO27001 信息安全管理体系认证
- 人力资源服务许可证
其他资质一律不写。
```

## 三、红线三：不写承诺

AI 喜欢写"我们承诺提供7x24小时服务"。这种承诺写进去就是合同义务，做不到就是违约。

### （一）怎么管住它

**在系统提示词里设定：涉及服务承诺的内容，必须标注待确认。**

```
涉及服务承诺、响应时间、人员数量等具体数字的内容，
用 [待补: 确认响应时间] 标注，不要自己编数字。
```
