# 主题生成器

> 按描述或参考图生成新的排版主题，自动派生全套组件。

## 什么时候使用

当用户说：
- "生成一个XX风格的主题"
- "我想要XX配色的排版"
- "按照这张图的风格排版"（附带参考图）
- "创建一个新主题，主色是XX"

## 工作流

### Step 1: 收集主题参数

从用户描述中提取：
- **主题名称**：英文代号（如 `warm-paper`），中文名（如 `暖纸`）
- **主色**：核心强调色（1 个）
- **点缀色**：辅助色（1 个，用于引用竖线、标签等）
- **底色**：正文背景色（通常白色或浅米色）
- **正文色**：段落文字色（通常深灰）
- **风格关键词**：温暖/冷峻/极简/活泼/严肃...

如果用户提供参考图：
1. 分析图片的主色调和配色
2. 提取 3-5 个核心色
3. 映射到主题参数（主色/点缀色/底色/正文色）

### Step 2: 派生色板

从核心色自动派生全套色板：

```
主色 → 用户指定
点缀色 → 用户指定
浅底色 = 主色与白色混合 90%（main + 90% white）
正文色 = #333333（所有主题统一，保证可读性）
辅助灰 = #999999（所有主题统一）
分割线色 = #dddddd（所有主题统一）
下划线色 = 点缀色与白色混合 60%（accent + 60% white）
代码块底色 = #f5f5f5（所有主题统一）
引用块底色 = 浅底色
```

### Step 3: 生成组件库

以 `theme-silicon-minimal.md` 为模板，替换色值：

1. 复制硅基极简的 20 个组件
2. 将 `#1a1a1a` 替换为新主色
3. 将 `#4e6b99` 替换为新点缀色
4. 将 `#f7f7f7` 替换为新引用块底色
5. 将 `#a0c4e8` 替换为新下划线色
6. 保持正文色 `#333`、辅助灰 `#999`、分割线 `#ddd` 不变
7. 根据风格关键词微调：
   - "温暖" → 圆角增大到 12px，行高增到 1.9
   - "冷峻" → 圆角减到 2px，字间距增到 1px
   - "极简" → 去掉所有装饰（竖线/底色），只保留加粗
   - "活泼" → 标题色用点缀色而非主色

### Step 4: 注册主题

1. 保存为 `references/theme-<name>.md`
2. 在 `references/theme-index.md` 中添加一行
3. 运行 `python scripts/component_lint.py references/theme-<name>.md`
4. 生成预览 HTML 到 `assets/theme-previews/<name>.html`

### Step 5: 预览确认

用 `assets/sample-article.md` 作为输入，用新主题排版生成预览 HTML，展示给用户确认。

## 色值混合公式

```
mix(color, white, ratio):
    r = int(color.r * (1-ratio) + 255 * ratio)
    g = int(color.g * (1-ratio) + 255 * ratio)
    b = int(color.b * (1-ratio) + 255 * ratio)
    return rgb(r, g, b)
```

例如：主色 `#4e6b99`，混合 90% 白色：
- r = int(0x4e * 0.1 + 255 * 0.9) = int(7.8 + 229.5) = 237 = 0xED
- g = int(0x6b * 0.1 + 255 * 0.9) = int(10.7 + 229.5) = 240 = 0xF0
- b = int(0x99 * 0.1 + 255 * 0.9) = int(15.3 + 229.5) = 244 = 0xF4
- 结果：`#EDF0F4`

## 风格预设

| 风格关键词 | 圆角 | 行高 | 字间距 | 标题色 | 引用竖线 |
|-----------|------|------|--------|--------|---------|
| 极简（默认） | 8px | 1.8 | 0.5px | 主色 | 有 |
| 温暖 | 12px | 1.9 | 0.5px | 主色 | 有 |
| 冷峻 | 2px | 1.7 | 1px | 主色 | 有 |
| 活泼 | 12px | 1.8 | 0.5px | 点缀色 | 有 |
| 极简无框 | 0 | 1.8 | 0.5px | 主色 | 无 |

## 注意事项

1. 正文色 `#333` 和辅助灰 `#999` 在所有主题中保持不变，确保可读性
2. 代码块底色 `#f5f5f5` 在所有主题中保持不变，确保代码可读
3. 新主题生成后必须通过 `component_lint.py` 检查
4. 新主题必须用 `sample-article.md` 生成预览，人工确认效果后再注册
